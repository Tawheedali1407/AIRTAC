# Your knowledge library

Put files in `knowledge/<shelf>/` or drop them on the **Knowledge** page.
- **Formats:** PDF, Markdown, text, HTML, Word.
- **Shelves:** `medicine`, `engineering`, `coding`, `study`, or any name you like.
- **Indexing:** AIRTAC reads new files every 5 minutes. With `nomic-embed-text` pulled it also searches by meaning. Answers name the book and page they used.

## Free books to start with (check each book's licence page; most are CC BY 4.0)
- **OpenStax** (openstax.org):
  - Anatomy and Physiology
  - Microbiology
  - Biology
  - Chemistry
  - University Physics (3 volumes)
  - Calculus (3 volumes)
  - Introductory Statistics
  - Introduction to Python Programming
- **Official documentation:**
  - the Python docs (docs.python.org: download as PDF or HTML)
  - MDN for the web (CC BY-SA)
  - your framework's docs
- **Your own material:**
  - lecture notes,
  - your syllabus PDFs,
  - lab manuals,
  - EduSkills module notes,
  - previous question papers you're allowed to keep.

Don't add copyrighted books you don't own a copy of, or anything you wouldn't want indexed on your own PC.

## Limits
A few thousand passages search in well under a second. Whole encyclopedias (Wikipedia, WikiMed through Kiwix) need the vector index planned in ROADMAP phase 3 (sqlite-vec).

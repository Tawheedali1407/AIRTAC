                            Reverse engineering
                            
        
                            Say what you want to build or learn: AIRTAC finds a suitable public GitHub repo itself (open-source licence,
          active, not huge), clones it on this PC, reads it and does the task with it as the reference. It only reads the files;
          nothing from it is run, and what the repo says is never taken as instructions.
                            
        
                            
          
          
        
                            
        
                              
        
                              
        
                              
        
                              Or take apart a project you already know:
                              
        
                              
          
          
          
          
        
                              
        
                              Compiled apps (.exe, .apk): REA (github.com/morluto/rea, MIT) does that with coding agents, but it needs macOS 12,
          Node 22 and a paid Hopper licence, so not on this PC. Only study software you own or whose licence allows it.
